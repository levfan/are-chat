# 情侣空间 3.0 · 50 项新功能总览（F100-F149）

> 本轮迭代继续以「情绪价值」为主线，聚焦五个此前未覆盖的情感缺口：
> **会说话**（把话说软、把话说甜）、**异地恋陪伴**（隔着屏幕也有牵手感）、
> **确定感与安全感**（把「我们会不会一直好下去」变成看得见的证据）、
> **趣味浪漫实验**（一起玩起来）、**深度日常陪伴**（懂 TA 的每一个小细节）。
> 全部功能不涉及照片/视频上传；内容类均为内置静态库，无第三方依赖。

## 质量基线

- 后端：`mvn -q compile` + `mvn test` 全绿（每批次补核心算法单测）
- 前端：`pnpm build`（vue-tsc）+ `pnpm test`（Vitest）全绿
- 推送事件：全部走 `ImPushService.pushCoupleEvent(Both)`，前端 `stores/couple.ts` 统一分发
